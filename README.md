# Soutine Seedance Prompts

**Prompt library / studio landing:** [https://soutine.ai/seedance-prompts](https://soutine.ai/seedance-prompts)

This package is a thin reference client for the free **Soutine Seedance Prompts** collection on [Soutine AI](https://soutine.ai/). Browse and copy prompts on the site; generation runs in the Soutine workspace.

## Install

```bash
pip install soutine-seedance-prompts
```

## Usage

```python
import soutine_seedance_prompts as lib
print(lib.LANDING)       # canonical deep link
print(lib.open_landing())  # returns the URL to open
```
